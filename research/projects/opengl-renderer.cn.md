# 基于 GPU（OpenGL）的渲染器开发

## 概览

长期个人项目：从零用 C++ 与现代 OpenGL 构建一个**实时渲染引擎**，
支持基于物理的着色、高质量阴影、符号距离场以及实时全局光照。在两年多
的时间里，代码库累积到 **15,000+ 行 C++/OpenGL**、**450+ 次提交**，
并研读了 **30+ 篇基础与前沿图形学论文**——其中复现了 **3 项 SIGGRAPH
工作**。

## 方法

- **基于物理的渲染。** Cook–Torrance BRDF、能量守恒的漫反射 + 镜面反射、
  正确的色调映射。
- **高质量阴影。** 级联阴影与 PCF/PCSS 软阴影。
- **符号距离场。** 基于 SDF 的几何与光线步进，用于隐式表面。
- **时空去噪。** 时间累积与边缘感知的空间滤波相结合，在低采样下保持
  低噪声。
- **实时全局光照。** 光探针与反射阴影图方案，再叠加屏幕空间贡献。

## 复现工作

- 3 项 SIGGRAPH 工作，每一项都缩减为可在自研引擎中运行的场景；
- 若干关于 BRDF、采样器与去噪的小规模论文。

## 收获

- 面向实时图形系统的高级 C++ 与现代 OpenGL 能力；
- GPU 架构、高性能计算与着色器编程；
- 多年如一日地搭建一个真正引擎的工程纪律，而非周末 demo。
